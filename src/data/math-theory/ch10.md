# Chapter 10 — Exponential and logarithmic functions

This chapter is about growth that multiplies, and about the logarithm that undoes that growth. Money in an account, a population, and a decaying substance can all follow the same idea: each step multiplies the current value by a fixed factor.

You do not need advanced calculus here. You need to read formulas, read graphs, and check which values are allowed. The guide follows the course map: exponential functions (10.1), logarithmic functions (10.2), and a short exam-style block (10.3).

On the exam, Chapter 10 almost always arrives as True/False packs. A short story or formula is given, then five independent claims. Each claim is either exactly true or false. The hard part is not arithmetic. It is knowing what each letter means, which factor belongs to which model, and which values a logarithm allows.

## Learning objectives

- Read $f(t)=a\cdot b^{t}$ and $P(t)=P_0 e^{kt}$, and say what the start and the base (or force) do to the graph.
- Tell continuous force $k$ apart from a discrete yearly factor $1+r$, including the trap $e^{k}$ versus $1+k$.
- Compute a doubling time or half-life, and recover a force from two positive observations.
- Read a logarithm as “the exponent that produces this number”, including intercepts and the asymptote on a graph.
- Use the product, quotient, and power log rules only when every separate argument is positive.
- Change base with $\log_{b} x=\ln x/\ln b$, and use the inverse identities with matching domains.
- Judge typical True/False claims by translating them into one clear statement about a factor, a force, or a domain.

## 10.1 Exponential functions

### Start with a picture

Think of a quantity that doubles every year. If you start with $100$, the next values are $200$, then $400$, then $800$. Each year you multiply by $2$. You do not add the same amount each time.

That is the heart of an exponential function: the variable sits in the **exponent**, and the level is multiplied again and again.

A typical formula is

$$
f(t)=a\cdot b^{t}.
$$

| Letter | Meaning | What changes if you change it |
| --- | --- | --- |
| $a$ | Starting height when $t=0$ (because $b^{0}=1$) | Moves the whole curve up or down |
| $b$ | The factor used in each step of length $1$ | Changes growth into decay, or changes the speed |
| $t$ | The input, often time | Moves you along the curve |

So $f(0)=a$, and

$$
f(t+1)=b\cdot f(t).
$$

This is different from a power function such as $t^{2}$, where the variable is the base. In $2^{t}$ the variable is the exponent. On the exam, a claim that treats $2^{t}$ as if it were a polynomial power is False.

**How this appears on the exam.** The stem often writes a letter formula and then claims something about “the start”, “the yearly factor”, or “the shape”. Before you mark True or False, name $a$ and $b$ in the story.

### Growth or decay: what the base does

Assume the start $a$ is positive.

| Base $b$ | What the graph does | Name |
| --- | --- | --- |
| $b>1$ | The curve rises | **growth** |
| $0<b<1$ | The curve falls | **decay** |

The height stays positive. With $a>0$, the exponential never reaches $0$ and never goes negative. There is no real $t$ with $b^{t}\le 0$.

[[FIGURE:exp-growth-decay|Growth uses a base bigger than 1. Decay uses a base between 0 and 1. Both curves stay above the horizontal axis.]]

**How to use this.** If a claim says “the path becomes negative after long enough”, mark it False for $a>0$. If a claim says “decay means the base is negative”, mark it False: decay uses $0<b<1$, not a negative base.

### What happens if you change the start

If you keep the same base (or the same force) but change the start $a$, the whole curve moves up or down. The shape stays the same. Only the height scale changes.

[[FIGURE:exp-start-level|Same growth speed, two different starts. The higher start sits above the lower one for every $t$.]]

A larger start does **not** change the force $k$ and does **not** change the doubling time. Those depend on the multiplier, not on how high you began.

### Continuous growth with $e$

Many course tasks write growth in the continuous form

$$
P(t)=P_0 e^{kt}.
$$

Here:

- $P_0>0$ is the start at time $t=0$;
- $e\approx 2.718$ is a fixed number (the natural base);
- $k$ is the **continuous force** (the continuous growth rate).

What this says in words:

- at time $0$, the value is $P_0$;
- after time $t$, the start has been multiplied by $e^{kt}$;
- over any interval of length $h$, the level is multiplied by $e^{kh}$;
- if $k>0$, the path grows;
- if $k<0$, the path decays;
- if $k=0$, the path stays flat.

Taking natural logs turns the formula into a straight line:

$$
\ln P(t)=\ln P_0+kt.
$$

That identity is the reason logs appear next to continuous growth on the exam. It is also the reason a plot of $\ln P$ against $t$ has slope $k$.

### What happens if you change the force $k$

A larger positive $k$ makes the curve rise faster. A smaller positive $k$ rises more slowly. Both curves can still start at the same $P_0$.

[[FIGURE:exp-force|Same start, two different forces. The steeper curve belongs to the larger $k$.]]

**Exam wording map.**

| Claim about $k$ | Meaning |
| --- | --- |
| “larger force” | steeper continuous path |
| “negative force” | decay |
| “force unchanged when $P_0$ changes” | True: $k$ is not the start |

### One-year growth: $e^{k}$ is not $1+k$

After one full unit of time, the continuous model multiplies by $e^{k}$.

A common False claim is that this factor equals $1+k$. That would replace $e^{kt}$ by $(1+k)^{t}$. Those are different functions.

For $k>0$,

$$
e^{k}>1+k,
$$

so continuous growth with force $k$ outruns the path $P_0(1+k)^{t}$. Equality holds only at $k=0$.

| Model | Formula | Factor over one year |
| --- | --- | --- |
| Continuous force $k$ | $P_0 e^{kt}$ | $e^{k}$ |
| Naive “rate $k$” | $P_0(1+k)^{t}$ | $1+k$ |
| Discrete annual rate $r$ | $P_0(1+r)^{t}$ | $1+r$ |

If a discrete yearly model should match a continuous force $k$, you need

$$
1+r=e^{k},
$$

so

$$
r=e^{k}-1,
$$

not $r=k$.

A discrete path can always be rewritten with a continuous force:

$$
(1+r)^{t}=e^{t\ln(1+r)}.
$$

The hidden continuous force inside the yearly factor $1+r$ is $\ln(1+r)$, not $r$.

**How this appears on the exam.** A stem places

$$
P(t)=P_0 e^{kt}\qquad\text{and}\qquad Q(t)=P_0(1+r)^{t}
$$

side by side, often with $1+r\neq e^{k}$. Typical claims:

- “the continuous one-year factor is $1+k$” → False;
- “$P$ and $Q$ coincide for every $t$” → False when the yearly factors differ;
- “if $r=k>0$, then $Q$ stays above $P$” → False, because $e^{k}>1+k$;
- “replacing $e^{kt}$ by $(1+k)^{t}$ changes nothing” → False.

**Example 1.** Take $k=0.05$. Then

$$
e^{0.05}\approx 1.05127,
$$

while $1+k=1.05$. Over many years the gap grows. A discrete annual rate that matches this continuous force is

$$
r=e^{0.05}-1\approx 0.05127,
$$

not $r=0.05$.

### Doubling time and half-life

Suppose $P(t)=P_0 e^{kt}$ with $k>0$. The **doubling time** $T$ is the time needed to reach $2P_0$:

$$
P(T)=2P_0
\quad\Longrightarrow\quad
e^{kT}=2
\quad\Longrightarrow\quad
T=\dfrac{\ln 2}{k}.
$$

The start $P_0$ cancels. Doubling does not depend on how large you began.

If the path decays as $P(t)=P_0 e^{-\lambda t}$ with $\lambda>0$, the **half-life** $H$ is the time to reach half of the start:

$$
P(H)=\dfrac12 P_0
\quad\Longrightarrow\quad
e^{-\lambda H}=\dfrac12
\quad\Longrightarrow\quad
H=\dfrac{\ln 2}{\lambda}.
$$

After one doubling period the level is $2P_0$. After two doubling periods it is $4P_0$, not $3P_0$. Doubling multiplies; it does not add.

If the exam gives the doubling time and asks for the force, invert the formula:

$$
k=\dfrac{\ln 2}{T}.
$$

**How this appears on the exam.** Claims often mix three ideas:

1. the formula $T=(\ln 2)/k$;
2. independence of $P_0$;
3. the meaning of two doublings ($4P_0$, never $3P_0$).

**Example 2.** A fund doubles every $14$ years under continuous force. Then

$$
k=\dfrac{\ln 2}{14}.
$$

The rebuilt path is $P(t)=P_0 e^{(\ln 2)\,t/14}$. At $t=28$ the fund has doubled twice, so the level is $4P_0$.

### Recovering the force from two observations

If a continuous path $P(t)=P_0 e^{kt}$ is known to be pure exponential, and two positive levels are observed at times $t_1<t_2$, then

$$
k=\dfrac{\ln P(t_2)-\ln P(t_1)}{t_2-t_1}
=\dfrac{1}{t_2-t_1}\ln\dfrac{P(t_2)}{P(t_1)}.
$$

This is a log chord. It is **not** the ordinary slope of the raw levels,

$$
\dfrac{P(t_2)-P(t_1)}{t_2-t_1}.
$$

That raw slope is not a continuous force.

Once $k$ is known, rebuild the path by anchoring at one observation:

$$
P(t)=P(t_1)\,e^{k(t-t_1)}.
$$

Watch the time shift carefully. The rewrite $P(t)=P(t_1)e^{k(t+t_1)}$ has the wrong sign pattern and fails already at $t=t_1$.

**How to use this on the exam.**

1. Confirm both levels are positive.
2. Form the ratio $P(t_2)/P(t_1)$, then take $\ln$.
3. Divide by the time gap.
4. Reject any claim that recovers $k$ from a raw level difference.

If a table is equally spaced in time and the ratios $P(t_{i+1})/P(t_i)$ are constant, one force fits. If those ratios jump, a single pure continuous force does not fit the whole table.

### Common exponential traps

| Claim | Why it fails |
| --- | --- |
| The continuous one-year factor is $1+k$ | It is $e^{k}$. |
| $e^{kt}$ and $(1+k)^{t}$ are the same | They agree only in special cases, not in general. |
| Doubling adds $P_0$ each time | Doubling multiplies by $2$. |
| A larger start changes the force $k$ | The start changes height, not $k$. |
| Force equals the raw slope of $P$ | Force comes from the slope of $\ln P$, or from a log ratio. |

## 10.2 Logarithmic functions

### What a logarithm is

A logarithm answers one question:

> What exponent do I put on the base to get this number?

For a base $b>0$ with $b\neq 1$, and for a positive number $x$,

$$
y=\log_{b} x
\quad\Longleftrightarrow\quad
b^{y}=x.
$$

Examples in words:

- $\log_{2} 8=3$ because $2^{3}=8$;
- $\log_{2}\!\left(\dfrac{1}{2}\right)=-1$ because $2^{-1}=\dfrac{1}{2}$;
- $\log_{b} 1=0$ because $b^{0}=1$;
- $\log_{b} b=1$ because $b^{1}=b$.

The **natural log** is $\ln x=\log_{e} x$. The **common log** is $\log_{10} x$.

**How to use this.** Every log claim can be rewritten as an exponential claim. If you are unsure whether a statement is true, convert it to $b^{y}=x$ and check.

### The graph of a logarithm

For $b>1$, the graph of $y=\log_{b} x$:

- is defined only for $x>0$;
- crosses the horizontal axis at $x=1$;
- passes through the point $(b,1)$;
- rises as $x$ grows (strictly increasing);
- never touches the vertical line $x=0$ (that line is an asymptote).

[[FIGURE:log-basic|Read the intercept $(1,0)$, the unit point $(2,1)$ for base $2$, and the vertical asymptote at $x=0$.]]

Zero and negative inputs are not allowed. A claim that “$x=0$ is fine for a log” is False.

**How this appears on the exam.** Graph packs ask you to read marked points and the asymptote. Typical True claims: $f(1)=0$, asymptote $x=0$, domain $(0,\infty)$. Typical False claims: “decreasing for every base $b>1$”, “$x=0$ is allowed”, “$f(1/2)=1$” for base $2$ (the true value is $-1$).

### What happens if you change the base

Every valid base still satisfies $\log_{b} 1=0$. For $x>1$, a larger base makes the log grow more slowly.

[[FIGURE:log-bases|Both curves meet at $(1,0)$. On the right, $\log_{10}$ stays below $\log_{2}$.]]

If $0<b<1$, the log is decreasing instead of increasing. Most exam bases are bigger than $1$, so “every base gives an increasing log” is still a False slogan when the stem allows $0<b<1$.

### Logs and exponentials undo each other

$$
\log_{b}\!\left(b^{t}\right)=t
\qquad\text{for every real }t,
$$

$$
b^{\log_{b} x}=x
\qquad\text{for every }x>0.
$$

So a log undoes an exponential with the same base, and an exponential undoes a log with the same base.

Domain matching matters in compositions. The expression $\log_{b}(b^{t})$ is fine for every real $t$. The expression $b^{\log_{b} x}$ needs $x>0$. A nested log such as $\log_{b}(\log_{b} x)$ needs the inner log itself to be positive, which is stricter than $x>0$. For base $2$, that means $x>1$, not merely $x>0$.

### The three log rules

For positive $x$ and $y$, and any real $r$,

$$
\log_{b}(xy)=\log_{b} x+\log_{b} y,
$$

$$
\log_{b}\!\left(\dfrac{x}{y}\right)=\log_{b} x-\log_{b} y,
$$

$$
\log_{b}\!\left(x^{r}\right)=r\log_{b} x.
$$

Each rule needs positive arguments where the separate logs appear.

Important trap: if $x$ and $y$ are both negative, then $xy$ can be positive, so $\log_{b}(xy)$ may exist. But $\log_{b} x$ and $\log_{b} y$ do not exist. Writing

$$
\log_{b}(xy)=\log_{b} x+\log_{b} y
$$

in that case is False.

Also False in general:

$$
\log_{b}(x+y)=\log_{b} x+\log_{b} y.
$$

**How this appears on the exam.** Letter identities are often true on the safe domain and false when the domain is ignored. Before you accept a split into a sum or difference, check that **each** piece is positive.

### Domain, step by step

Before you simplify a log expression, ask: is every log argument positive?

Work in this order:

1. Write the inequality “argument $>0$” for each log.
2. Add any inner restrictions (denominators not zero, roots defined, and so on).
3. Only then apply a log rule or evaluate a point.

For $\log(2x-6)$ you need $2x-6>0$, so $x>3$. For a sum of two logs, each argument must be positive on its own. Combining into one log of a product does not remove that separate-check habit when the original expression was written as a sum.

### Change of base

Any log can be rewritten with natural logs:

$$
\log_{b} x=\dfrac{\ln x}{\ln b}=\dfrac{\log_{c} x}{\log_{c} b}.
$$

This is an exact identity, not an approximation. A useful special case is

$$
\log_{b} a=\dfrac{1}{\log_{a} b}
$$

when both bases are valid.

**How to use this.** If a table or claim switches between $\log_{2}$, $\ln$, and $\log_{10}$, rewrite everything with one base before comparing.

### Common logarithm traps

| Claim | Why it fails |
| --- | --- |
| Logs accept $x\le 0$ | The argument must be $>0$. |
| $\log(x+y)=\log x+\log y$ | That is not a log rule. |
| Split $\log(xy)$ when $x,y<0$ | Each separate log is undefined. |
| Every base gives an increasing log | Only bases $b>1$ increase. |
| Nested logs need only $x>0$ | Each intermediate log must also be positive. |

## 10.3 Exam-Style

These two packs match the course True/False style. Work every letter. The solutions below show the full working order, not only the final True/False mark.

### Example A — Continuous versus discrete

A stock follows $P(t)=P_0 e^{kt}$ with $P_0>0$ and $k>0$. A rival path is $Q(t)=P_0(1+r)^{t}$ with $r>0$ and $1+r\neq e^{k}$.

**A.** For every $t>0$, the continuous one-year factor equals $1+k$.

**B.** The paths $P$ and $Q$ agree for every $t\ge 0$.

**C.** If $r=k$, then $Q(t)>P(t)$ for every $t>0$.

**D.** The continuous doubling time is $T=\dfrac{\ln 2}{k}$, and it does not depend on $P_0$.

**E.** Replacing $e^{kt}$ by $(1+k)^{t}$ leaves every value of $P$ unchanged.

**Solutions.**

First write the two one-year multipliers side by side:

$$
\frac{P(t+1)}{P(t)}=e^{k},
\qquad
\frac{Q(t+1)}{Q(t)}=1+r.
$$

The stem keeps $1+r\neq e^{k}$, so after time $0$ the paths cannot stay together. Also keep the inequality $e^{k}>1+k$ for $k>0$ in mind. That single comparison decides several letters.

**A.** False. After one year the continuous model multiplies by $e^{k}$, not by $1+k$. The slogan “rate $k$ means factor $1+k$” belongs to the naive path $P_0(1+k)^{t}$, not to $P_0 e^{kt}$.

**B.** False. At $t=0$ both start at $P_0$. For $t>0$,

$$
P(t)=P_0 e^{kt},\qquad Q(t)=P_0(1+r)^{t}.
$$

Because $e^{k}\neq 1+r$, these are different geometric paths. They cannot agree for every $t\ge 0$.

**C.** False. Set $r=k>0$. Then $Q(t)=P_0(1+k)^{t}$ while $P(t)=P_0 e^{kt}$. Since $e^{k}>1+k$, we get $P(t)>Q(t)$ for every $t>0$. The claim has the inequality the wrong way round.

**D.** True. Solve $P(T)=2P_0$:

$$
P_0 e^{kT}=2P_0
\quad\Longrightarrow\quad
e^{kT}=2
\quad\Longrightarrow\quad
T=\dfrac{\ln 2}{k}.
$$

The start $P_0$ cancels, so the doubling time does not depend on $P_0$.

**E.** False. Replacing $e^{kt}$ by $(1+k)^{t}$ produces a different function whenever $k\neq 0$. Already at $t=1$ the values $P_0 e^{k}$ and $P_0(1+k)$ disagree.

### Example B — Reading a logarithm

Let $f(x)=\log_{2} x$ for $x>0$.

**A.** The graph meets the horizontal axis at $x=1$, so $f(1)=0$.

**B.** For every base $b>1$, the logarithm is strictly decreasing.

**C.** $f$ is strictly decreasing on $(0,\infty)$.

**D.** The argument $x=0$ is allowed in the domain of $f$.

**E.** $f\!\left(\dfrac{1}{2}\right)=1$.

**Solutions.**

Translate every claim back to the definition $y=\log_{2} x\Leftrightarrow 2^{y}=x$, and remember that base $2>1$ makes the log strictly increasing on $(0,\infty)$.

**A.** True. The horizontal intercept means $f(x)=0$. By definition,

$$
\log_{2} 1=0\quad\text{because}\quad 2^{0}=1.
$$

So the graph meets the axis at $x=1$.

**B.** False. For every base $b>1$, $\log_{b}$ is strictly **increasing**, not decreasing. Decreasing behaviour appears only for bases in $(0,1)$.

**C.** False. Here the base is $2>1$, so $f$ is strictly increasing on $(0,\infty)$. For a quick check: $f(1)=0$ and $f(2)=1$, so the values rise as $x$ rises.

**D.** False. The definition requires a positive argument. At $x=0$ there is no real $y$ with $2^{y}=0$. The line $x=0$ is an asymptote, not a point on the graph.

**E.** False. We need $y$ such that $2^{y}=1/2$. That exponent is $y=-1$, not $1$:

$$
f\!\left(\dfrac{1}{2}\right)=\log_{2}\!\left(\dfrac{1}{2}\right)=-1.
$$

The value $1$ would mean $2^{1}=2$, which is the point $(2,1)$, not $(1/2,1)$.

## Summary reference

| Question | What to do |
| --- | --- |
| Is it exponential? | The variable is in the exponent. |
| What does the start do? | Changes height. Same shape if $k$ (or $b$) is fixed. |
| What does $k$ do? | Larger positive $k$ rises faster. |
| One-year continuous factor | Use $e^{k}$, not $1+k$. |
| Match discrete $r$ to force $k$ | Set $1+r=e^{k}$, i.e. $r=e^{k}-1$. |
| Doubling time | $T=\dfrac{\ln 2}{k}$. |
| Half-life | $H=\dfrac{\ln 2}{\lambda}$ for $P_0 e^{-\lambda t}$. |
| Recover force from two points | $k=\dfrac{1}{t_2-t_1}\ln\dfrac{P(t_2)}{P(t_1)}$. |
| Meaning of $\log_{b} x$ | The exponent $y$ with $b^{y}=x$. |
| Log domain | Argument $>0$. |
| Log product / quotient / power | Use the three rules only with positive pieces. |
| Change of base | $\log_{b} x=\dfrac{\ln x}{\ln b}$. |

Central formulas:

$$
P(t)=P_0 e^{kt},
$$

$$
\ln P(t)=\ln P_0+kt,
$$

$$
T=\dfrac{\ln 2}{k}\quad(k>0),
$$

$$
y=\log_{b} x\ \Longleftrightarrow\ b^{y}=x\quad(x>0),
$$

$$
\log_{b} x=\dfrac{\ln x}{\ln b}.
$$

**Working order.** Name the model. Say what each letter does. For continuous versus discrete, write the one-year factors first. For logs, convert to exponential form and check the domain before using a rule. Then decide True or False.

**Self-check.** Can you explain growth versus decay from the base alone? What does a larger $P_0$ do to the graph? What does a larger $k$ do? Why is $e^{k}$ not the same as $1+k$? How do you recover $k$ from two positive observations? What question does $\log_{b} x$ answer? Why is $x=0$ never in a log domain? When is it wrong to split $\log(xy)$ into a sum?
