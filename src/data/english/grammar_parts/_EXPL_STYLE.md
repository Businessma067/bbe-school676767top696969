# English Grammar explanation style (v3)

Rewrite ONLY `tactical_explanations` (and keep `solution_overview` unused by UI — leave as-is).
KEEP statements, answer_key, highlights, ids, difficulty, sort_order unchanged.

## Per-statement shape

```
**A) <exact statement text>.**

2–4 living tutorial sentences (always — never shorten just to add/remove Tip/Trap).

[optional Tip or Trap — see rules]

Closing verdict sentence (required).
```

### Closing verdict (required, every item)
Do NOT end with bare `(true)` / `(false)`.
Do NOT reuse the stiff templates:
- ~~`So the statement holds: …`~~
- ~~`So the statement is false: repair to "…".`~~

Write **one natural closing sentence grounded in this item’s grammar point**. Vary the phrasing across the bank — read the body, then lead into the verdict the way a coach would say it out loud.

Must still make the true/false call unmistakable for this letter.

**True** — accept / keep / that works / this is sound, with a short why tied to the rule just taught, e.g.:
- `Keep this: present perfect correctly marks the open span from April to now.`
- `That pairing is sound — continuous background plus simple interrupt.`
- `Accept the line: past perfect correctly marks the earlier past action.`

**False** — reject / mark wrong / that fails, and give the fixed wording in quotes when a clean repair exists, e.g.:
- `Mark it wrong and prefer "Maya finished her chemistry lab report last Tuesday."`
- `That tense choice fails here — rewrite as "Leo used to swim before school every morning."`
- `Reject this near-miss; the clean version is "The guests had already left when the dessert trolley arrived."`

The closing must feel specific to the mistake or success just explained — not a copy-paste stamp.

### Tip / Trap (optional — analyze each item)
- Use **Trap:** only when the false wording is a real near-miss / exam trap (looks plausible). Prefer mid/hard items (difficulty 3–5). Soft false that is obviously wrong → no Trap label; just explain, then closing verdict.
- Use **Tip:** only when a short memorable cue adds something the body did not already say. Easy obvious trues → usually no Tip.
- If Tip/Trap would merely restate the paragraph, omit it. Omitting must NOT cut the main sentences.
- Tip/Trap decisions already present may stay unless clearly wrong; focus the rewrite on the closing + keep bodies full.

### Format notes
- Letter A–E matches index; claim repeats the exact statement.
- UTF-8, no mojibake. Valid JSON. No commit.
