Expected Value, Variance & Standard 
Deviation — Practice Questions 
Topic: E(X), Var(X), and σ — five questions, five different styles 
Each question below uses a different presentation: a plain probability table, a dice-based combinatorial setup, a 
business/finance payoff scenario, a game with a linear fee adjustment, and a quality-control defect count. All use the 
same three core quantities — E(X), Var(X), and the standard deviation σ — computed the same way every time: σ² 
= Var(X) = E(X²) − [E(X)]², and σ = √Var(X). As with the other sets in this series, the number of TRUE statements 
is not fixed — it ranges from all five true to just one true, depending on the question.

random variable is a table lookup (Questions 1, 3, 5), a combinatorial count (Question 2), or a transformed payout 
(Question 4). And remember the one rule that trips people up most often: adding or subtracting a constant shifts 
E(X) but leaves Var(X) and σ completely unchanged — only multiplying X by a constant a changes the spread, and it 
does so by a factor of a² for the variance and |a| for σ.

Expected Value, Variance & Standard 
Deviation — Practice Questions (Part 2) 
Six more questions in varied styles — continuous uniform, Poisson, a difference of variables, a weighted portfolio, the 
empirical rule, and a missing-parameter puzzle 
A continuation of the previous set, using μ (mu) for the mean, σ (sigma) for the standard deviation, and σ² (sigma-squared) 
for the variance throughout, instead of the E(X)/Var(X)/SD(X) notation used before. Every question has five True/False 
statements (A–E). 
Notation and formulas used throughout: 
● μ = E(X) — the mean (expected value) of a random variable. 
● σ² = Var(X) = E(X²) − μ² — the variance. 
● σ = √σ² — the standard deviation, in the same units as X. 
● Linear transformation Y = aX + b: μ_Y = a·μ_X + b, and σ²_Y = a²·σ²_X, so σ_Y = |a|·σ_X. 
● Independent X, Y: μ_(X±Y) = μ_X ± μ_Y always, and σ²_(X±Y) = σ²_X + σ²_Y — variances ADD whether you're 
taking a sum or a difference, as long as X and Y are independent. σ itself is never simply additive. 
● Continuous Uniform on [a, b]: μ = (a+b)/2, and σ² = (b−a)²/12. 
● Poisson with rate λ: μ = λ, and σ² = λ (mean and variance are equal). 
● Empirical rule (for approximately normal data): about 68% of values fall within μ ± 1σ, and about 95% fall within μ 
± 2σ.

Question 2 — A Call Center

μ = λ = 6. σ² = λ = 6. σ = √6 ≈ 2.449. 
A TRUE 
μ = 6 calls per hour, as given. 
Formula: μ = λ, for a Poisson(λ) random variable 
B TRUE

Formula: σ² = λ = μ, for a Poisson(λ) random variable 
C FALSE

Formula: σ = √λ 
D FALSE 
If λ doubles to 12, the new σ = √12 ≈ 3.464. Doubling 2.449 would give 4.899, but 3.464 is not equal to that — σ scales by

Formula: σ = √λ scales by √2 when λ doubles, not by 2 
E TRUE 
If λ doubles to 12, the new σ² = 12, which is exactly double the original σ² = 6. Since σ² = λ directly, doubling λ always

Question 3 — Company Profit 
Step 1 — Apply the rules for a difference of independent random variables. 
μ(Profit) = μ(R) − μ(C) = 50,000 − 32,000 = $18,000. This subtraction rule for the mean holds regardless of independence. 
σ²(Profit) = σ²(R) + σ²(C) = 4,000,000 + 1,000,000 = 5,000,000 — the variances ADD, even though Profit is a difference, 
because R and C are independent. σ(Profit) = √5,000,000 ≈ $2,236.07. 
A TRUE

Formula: μ(R−C) = μ(R) − μ(C)

σ²(C), which would give 4,000,000 − 1,000,000 = 3,000,000. Variances always add for independent variables, whether you're 
computing a sum or a difference — subtracting the random variables does not mean subtracting their variances. 
Formula: σ²(R−C) = σ²(R) + σ²(C), for independent R and C — NOT σ²(R) − σ²(C)

σ(Profit) ≈ $2,236.07, which is greater than $2,200.

Question 4 — An Investment Portfolio 
Step 1 — Apply the weighted-sum rules for two independent random variables. 
For weights 0.6 and 0.4: μ(portfolio) = 0.6×μ(A) + 0.4×μ(B) = 0.6×8 + 0.4×5 = 4.8 + 2 = 6.8%. 
Because the weights multiply the random variables (not just get averaged), each weight must be SQUARED when combining 
variances: σ²(portfolio) = 0.6²×σ²(A) + 0.4²×σ²(B) = 0.36×25 + 0.16×16 = 9 + 2.56 = 11.56. σ(portfolio) = √11.56 = 3.4%. 
A TRUE 
μ(portfolio) = 6.8%, as computed above. 
Formula: μ(wA·A + wB·B) = wA·μ(A) + wB·μ(B) 
B FALSE 
This uses the weights directly instead of squaring them: 0.6×25 + 0.4×16 = 15 + 6.4 = 21.4, which does not equal the correct 
σ²(portfolio) = 11.56. This is a common error — variance combines with the SQUARE of each weight, not the weight itself, 
because Var(wX) = w²Var(X). 
Formula: σ²(wA·A + wB·B) = wA²·σ²(A) + wB²·σ²(B), NOT wA·σ²(A) + wB·σ²(B) 
C TRUE 
σ(portfolio) = √11.56 = 3.4% exactly, as computed in Step 1. 
Formula: σ(portfolio) = √σ²(portfolio) 
D TRUE 
σ(A) = √25 = 5%, and σ(B) = √16 = 4%. The weighted average is 0.6×5 + 0.4×4 = 3+1.6 = 4.6%. The portfolio's actual σ = 
3.4%, which is less than 4.6% — this is the mathematical basis of diversification: combining two independent, imperfectly-
correlated assets produces a portfolio less volatile than a simple weighted average of their individual volatilities. 
Formula: σ(portfolio) < wA·σ(A) + wB·σ(B), for independent assets — the diversification effect 
E FALSE 
σ²(portfolio) = 11.56, which is not greater than σ²(B) = 16 — it's smaller. Even though Stock B alone is less volatile than the 
naive combination might suggest, blending it with Stock A (a partially offsetting independent asset) at a 40% weight still 
results in a portfolio variance below B's own variance. 
Formula: Compare σ²(portfolio) = 11.56 to σ²(B) = 16

Question 6 — Find the Missing Value 
Step 1 — Solve for k using the given mean, μ = 8. 
μ = (0)(0.5) + (10)(0.3) + (k)(0.2) = 0 + 3 + 0.2k. Setting this equal to 8: 3 + 0.2k = 8, so 0.2k = 5, giving k = 25. 
Step 2 — Compute σ² and σ using k = 25. 
E(X²) = (0²)(0.5) + (10²)(0.3) + (25²)(0.2) = 0 + 30 + 125 = 155. σ² = 155 − 8² = 155 − 64 = 91. σ = √91 ≈ 9.539. 
A TRUE 
k = 25, exactly as solved in Step 1. 
Formula: Solve μ = Σx·P(X=x) for the unknown value 
B TRUE 
σ² = 91 exactly, as computed in Step 2. 
Formula: σ² = E(X²) − μ² 
C FALSE 
σ ≈ 9.539, which is not greater than 10 — a close call worth the extra decimal place. 
Formula: σ = √σ² 
D TRUE 
Redoing Step 1 with μ = 6 instead of 8: 3 + 0.2k = 6, so 0.2k = 3, giving k = 15. Since 15 is smaller than 25, the statement is 
true. This makes sense: k carries only a 0.2 probability weight, so pulling the overall mean down requires k itself to be 
smaller. 
Formula: Re-solve 3 + 0.2k = μ for a different target μ 
E FALSE 
Each value's contribution to σ² is P(x)×(x−μ)². For x=10: 0.3×(10−8)² = 0.3×4 = 1.2. For x=25: 0.2×(25−8)² = 0.2×289 = 
57.8. The contribution from x=25 (57.8) is far larger than from x=10 (1.2), so the statement — which claims the opposite — 
is false. Even though x=10 has a higher probability (0.3 vs. 0.2), its distance from the mean is small (only 2 units), while

Expected Value, Variance & Standard Deviation — Practice 
Questions (Part 6) 
Six harder questions on discrete probability distributions, building conceptual complexity rather than just longer 
arithmetic: solving for unknown probabilities from a mean constraint, combining independent random variables, a 
nonlinear function of X, comparing two distributions with equal mean but different spread (including variance-
contribution reasoning), a break-even fee that leaves variance untouched, and the total payout across two 
independent policies. As before, E(X), Var(X), and SD(X) are written out in full rather than as μ/σ²/σ symbols. 
E(X) is the mean (expected value), Var(X) is the variance, and SD(X) is the standard deviation. Every question has 
five True/False statements (A–E), and the number of TRUE statements varies from question to question — read 
every statement on its own merits. 
Notation and formulas used throughout: 
● E(X) = Σ x·P(X=x) — the mean (expected value) of a discrete random variable. 
● Var(X) = E(X²) − E(X)², where E(X²) = Σ x²·P(X=x) — the variance. 
● SD(X) = √Var(X) — the standard deviation, in the same units as X. 
● Linear transformation Y = aX + b: E(Y) = a·E(X) + b, and Var(Y) = a²·Var(X), so SD(Y) = |a|·SD(X). 
● Contribution of a value x to Var(X): P(x)·(x − E(X))² — these contributions sum to Var(X) across all 
values of X. 
● Independent X₁, X₂: E(X₁+X₂) = E(X₁)+E(X₂) always, and Var(X₁+X₂) = Var(X₁)+Var(X₂) when X₁ and 
X₂ are independent — but SD does not add.
