Task 1. Basic operations on explicit sets
(source: 1-10logic.docx, original Task 1 — difficulty score 1/8)
Let A = {1, 2, 3, 4, 5}, B = {3, 4, 5, 6, 7}, and C = {5, 6, 7, 8, 9}.
General Solution: Compute the key sets once: A ∩ B = {3, 4, 5}; A ∪ C covers 1–5 (from A) and 5–9 (from C)
with no gaps, so A ∪ C = {1,...,9}; A \ C removes only the shared element 5, leaving {1,2,3,4}; and B ∩ C =
{5,6,7} (nonempty, so B and C are NOT disjoint). Every statement below reduces to comparing against one of these
four computed sets.
a) A ∩ B = {3, 4, 5}.
b) A ∪ C = {1, 2, 3, 4, 5, 6, 7, 8}.
c) (A ∩ B) ∩ C = {5}.
d) A \ C = {1, 2, 3}.
e) B and C are disjoint sets.
Explanations:
a) True. The elements common to both A and B are 3, 4, and 5.
b) False. Trap: A contributes 1–5, C contributes 5–9, so together they cover every integer from 1 to 9 — the
statement's set stops at 8 and wrongly omits 9, which C contributes.
c) True. A ∩ B = {3,4,5}; intersecting this with C = {5,6,7,8,9} leaves only the common element 5.
d) False. A \ C removes from A any elements that are also in C. Only 5 is in both, so A \ C = {1,2,3,4} — the
statement is missing the element 4.
e) False. B and C share the elements 5, 6, and 7, so they are not disjoint (disjoint would require B ∩ C = ∅).

and |A| = 2. Restricting to natural numbers (non-negative) as in set C eliminates −3, leaving C = {3} — a single
element, not two.
a) A = B.

b) 3 ∈ A.
c) A = {3} (only the positive root).
d) |A| = 2.
e) The set C = {x ∈ N : x² = 9} (N = natural numbers) is equal to {3, −3}.
Explanations:
a) True. Both 3 and −3 satisfy x² = 9, and these are the only integer solutions, so A = {3, −3} = B.
b) True. 3² = 9, so 3 satisfies the defining condition and belongs to A.
c) False. −3 also satisfies (−3)² = 9 and is an integer, so it must be included in A as well; A has two elements,

Task 3. Subsets, elements, and the power set
(source: 1-10logic.docx, original Task 2 — difficulty score 2/8)
Let A = {a, b, c}.
General Solution: A has 3 elements, so |P(A)| = 2³ = 8, and its subsets are ∅, {a}, {b}, {c}, {a,b}, {a,c}, {b,c},
{a,b,c}. Keep the elements of A (a, b, c) separate from the elements of P(A), which are themselves subsets like {a,b}
— that distinction, plus the definition of "proper subset" (strictly smaller), resolves every statement below.
a) The power set of A has 8 elements.
b) {a, b} is an element of A.
c) ∅ is a subset of A.
d) A is a proper subset of A.
e) There are exactly 3 subsets of A that contain exactly 2 elements.
Explanations:
a) True. A set with 3 elements has 2³ = 8 subsets in total, so its power set contains 8 elements.
b) False. The elements of A are a, b, and c individually. {a,b} is a subset of A, not an element of A —
confusing “element of” with “subset of” is a common mistake.
c) True. The empty set is a subset of every set, including A.
d) False. A proper subset must be strictly smaller than the original set (not equal to it). Since A = A, A is not a
proper subset of itself.
e) True. The 2-element subsets are {a,b}, {a,c}, and {b,c} — exactly three of them.
Task 4
(source: 0_1-0_10logic.docx, original Task 19 — difficulty score 2/8)
Context: Let D = {a, b, c}.
General Solution: |D|=3 ⇒ |P(D)|=2³=8 subsets: ∅,{a},{b},{c},{a,b},{a,c},{b,c},{a,b,c}. Keep straight: ∅⊆D
(subset) is always true, but ∅∈D (element) is generally false; likewise {a} ⊆D is true but {a} ∈D is false (D's elements
are a,b,c themselves, not the set {a}).
Statements (True / False):
a) ∅ ⊆ D
b) ∅ ∈ D
===== PAGE 3 =====
c) D has exactly 8 subsets
d) Both {a} ⊆ D and {a} ∈ D are true
e) D ⊆ D
Answers & Explanations:
a) TRUE. By definition, the empty set is a subset of every set, since it has no elements that could violate the
subset condition.
b) FALSE. Trap: being a subset (∅ ⊆ D) is different from being an element (∅ ∈ D). D's elements are a, b, and c
— the empty set is not one of them.
c) TRUE. A set with n elements has 2ⁿ subsets. Here n = 3, so D has 2³ = 8 subsets: ∅, {a}, {b}, {c}, {a,b},
{a,c}, {b,c}, {a,b,c}.
d) FALSE. Trap: {a} ⊆ D is true (a is an element of D, so the set {a} is contained in D), but {a} ∈ D is false —
D's elements are a, b, c themselves, not the set {a}.
e) TRUE. Every set is a subset of itself, since every element of D is trivially an element of D.
Task 5
(source: 0_1-0_10logic.docx, original Task 21 — difficulty score 2/8)
Context: Let E = {1, 3, 5, 7} and F = {3, 4, 5, 6}.
General Solution: Compute both directions separately since \ is NOT commutative: E\F={1,7} (removing 3,5
shared with F) and F\E={4,6} (removing 3,5 shared with E) — different sets. Their union {1,4,6,7} is the symmetric
difference E △F, and their intersection is always empty by construction.
Statements (True / False):
a) E \ F = {1, 7}
b) F \ E = {4, 6}
c) E \ F = F \ E
d) (E \ F) ∪ (F \ E) = {1, 4, 6, 7}
e) (E \ F) ∩ (F \ E) = ∅
Answers & Explanations:
a) TRUE. Removing from E every element also found in F (3 and 5) leaves {1, 7}.
b) TRUE. Removing from F every element also found in E (3 and 5) leaves {4, 6}.
c) FALSE. Trap: set difference is NOT commutative in general. E \ F = {1,7} while F \ E = {4,6} — these are
different sets, so the equality fails.
d) TRUE. The union of the two "one-sided" differences, {1,7} ∪ {4,6} = {1,4,6,7}, is exactly the symmetric
difference E △ F: the elements belonging to exactly one of the two sets.
e) TRUE. By construction, E \ F contains only elements outside F, and F \ E contains only elements outside E,
so the two sets can never share an element — their intersection is always empty.
Task 6. De Morgan's laws with a universal set
(source: 1-10logic.docx, original Task 4 — difficulty score 2/8)
Let U = {1, 2, ..., 10} be the universal set, A = {1, 2, 3, 4, 5}, and B = {4, 5, 6, 7, 8}.
General Solution: Compute once: A ∪ B = {1,...,8}, so (A∪B)ᶜ = {9,10}; A ∩ B = {4,5} (only elements in both),
so (A∩B)ᶜ = {1,2,3,6,7,8,9,10}. Both De Morgan identities, (A∪B)ᶜ=Aᶜ∩Bᶜ and (A∩B)ᶜ=Aᶜ∪Bᶜ, hold generally and
can be checked against these two computed values.
a) (A ∪ B)ᶜ = {9, 10}.
===== PAGE 4 =====
b) (A ∪ B)ᶜ = Aᶜ ∩ Bᶜ.
c) (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ.
d) A ∩ B = {4, 5, 6}.
e) (A ∩ B)ᶜ = {1, 2, 3, 4, 5, 9, 10}.
Explanations:
a) True. A ∪ B = {1,2,3,4,5,6,7,8}; taking the complement relative to U leaves exactly {9,10}.
b) True. This is De Morgan's law for sets, and it holds generally — the complement of a union equals the
intersection of the complements.
c) True. This is the other De Morgan's law — the complement of an intersection equals the union of the
complements — and it also holds generally.
d) False. A ∩ B consists of elements in both sets: only 4 and 5 qualify (6 is in B but not in A), so A ∩ B =
{4,5}, not {4,5,6}.
e) False. Since A ∩ B = {4,5}, its complement relative to U is everything else: {1,2,3,6,7,8,9,10}. The set given
here wrongly includes 4 and 5 and wrongly omits 6, 7, and 8.
Task 7. Cartesian products
(source: 1-10logic.docx, original Task 3 — difficulty score 2/8)
Let A = {1, 2} and B = {x, y, z}.
General Solution: |A×B| = |A|·|B| = 2·3 = 6 in both directions, but the pairs themselves differ: A×B always has its
FIRST coordinate from A, while B×A has its first coordinate from B — so (2,x) ∈ A×B but (x,2) ∉ A×B, and A×B
≠ B×A as sets of pairs even though |A×B| = |B×A|.
a) |A × B| = 6.
b) (2, x) ∈ A × B.
c) (x, 2) ∈ A × B.
d) A × B = B × A.
e) The number of elements in B × A equals the number of elements in A × B.
Explanations:
a) True. The Cartesian product A × B has |A| × |B| = 2 × 3 = 6 ordered pairs.
b) True. 2 ∈ A and x ∈ B, so the ordered pair (2,x), with first coordinate from A and second from B, belongs to
A × B.
c) False. In A × B, the first coordinate must come from A. Since x ∉ A, the pair (x,2) does not belong to A × B.
d) False. A × B contains pairs like (2,x) where the first entry is from A; B × A would need its first entry from
B, so e.g. (2,x) ∉ B × A since 2 ∉ B. The two products contain different pairs in general.
e) True. Even though the pairs themselves differ, both products contain |A| × |B| = |B| × |A| = 6 elements — the
counts match even when the sets of pairs don't.
Task 8
(source: 0_1-0_10logic.docx, original Task 15 — difficulty score 2/8)
Context: Let A = {2, 4, 6, 8, 10}, B = {3, 6, 9, 12}, and C = {1, 2, 3, 4, 5}.
General Solution: Compute once: A∩B={6}; A∪B={2,3,4,6,8,9,10,12} (8 elements); C\A={1,3,5} (only removing
2,4, shared with A); B\C={6,9,12} (removing 3, the only shared element); A∩C={2,4} (only elements in both).
Compare each statement below directly against these five reference values.
Statements (True / False):
===== PAGE 5 =====
a) A ∩ B = {6}
b) A ∪ B has 8 elements
c) C \ A = {1, 3}
d) B \ C = {3, 6, 9, 12}
e) A ∩ C = {2, 4, 6}
Answers & Explanations:
a) TRUE. The only element common to both A and B is 6, so A ∩ B = {6}.
b) TRUE. |A ∪ B| = |A| + |B| − |A ∩ B| = 5 + 4 − 1 = 8. Listing them out: {2,3,4,6,8,9,10,12} — indeed 8
elements.
c) FALSE. Trap: C \ A removes from C every element that is also in A. Since 2 and 4 belong to A, they are
removed — but 5 is NOT in A, so it must stay. The correct result is C \ A = {1, 3, 5}, not {1, 3} as stated; this
version wrongly drops the surviving element 5.
d) FALSE. This is the classic trap: B \ C must remove every element of B that also lies in C. Since 3 ∈ C, it
must be dropped. The correct result is B \ C = {6, 9, 12}, not {3, 6, 9, 12}.
e) FALSE. Another trap: 6 belongs to A but NOT to C, so it cannot appear in A ∩ C. The correct intersection is
A ∩ C = {2, 4}.
Task 9
(source: 0_11-0_20logic.docx, original Task 57 — difficulty score 2/8)
Context: In a cohort of 50 students, 30 take Mathematics (set M) and 25 take Economics (set E). The two courses
share 12 common students, so |M ∩ E| = 12.
General Solution: By inclusion-exclusion: |M∪E| = 30+25−12 = 43, so 50−43=7 take neither; |M only| =
30−12=18. Since |M∩E|=12 is less than |E|=25, E is NOT a subset of M (13 Econ-only students exist), and since
12≠0, M and E are not disjoint.
Statements (True / False):
a) |M ∪ E| = 43
b) The number of students taking neither Mathematics nor Economics is 7
c) M \ E has 18 students (those taking only Mathematics)
d) E ⊆ M
e) M and E are disjoint sets
Answers & Explanations:
a) TRUE. |M ∪ E| = |M| + |E| − |M ∩ E| = 30 + 25 − 12 = 43.
b) TRUE. Out of 50 students, 43 take at least one of the two courses, so 50 − 43 = 7 take neither.
c) TRUE. M \ E removes the 12 shared students from M's 30, leaving 30 − 12 = 18 students who take only
Mathematics.
d) FALSE. Trap: E ⊆ M would require every Economics student to also take Mathematics, i.e. |M ∩ E| = |E| =
25. But |M ∩ E| = 12 ≠ 25, so 13 Economics students do not take Mathematics — E is not a subset of M.
e) FALSE. Trap: disjoint sets must have an empty intersection. Here |M ∩ E| = 12 ≠ 0, so M and E overlap and
are therefore not disjoint.
Task 10
(source: 0_11-0_20logic.docx, original Task 59 — difficulty score 2/8)
Context: Let U = {1, 2, ..., 9}, and let A = {1, 2, 3}, B = {4, 5, 6}, C = {7, 8, 9}.
===== PAGE 6 =====
General Solution: A,B,C share no elements pairwise (pairwise disjoint) and together cover all of U, so {A,B,C} is a
genuine partition. Since A,B are already disjoint, A\B=A (nothing gets removed) — and disjoint sets need NOT be
empty themselves, only share no elements with each other.
Statements (True / False):
a) A, B, and C are pairwise disjoint
b) {A, B, C} forms a partition of U, since A ∪ B ∪ C = U and the sets are pairwise disjoint
c) A ∩ B ∩ C = ∅
d) A \ B = ∅
e) Since A ∩ B = ∅, it follows that A = ∅ or B = ∅
Answers & Explanations:
a) TRUE. No element is shared between any two of A, B, C, since each contains a distinct block of numbers —
so every pair of sets is disjoint.
b) TRUE. A ∪ B ∪ C = {1,...,9} = U, and the sets are pairwise disjoint and nonempty, which is exactly the
definition of a partition of U.
c) TRUE. Since even just A ∩ B is already empty, intersecting with C cannot add anything, so A ∩ B ∩ C = ∅.
d) FALSE. Trap: A \ B removes from A only the elements A shares with B. Since A and B are disjoint, nothing
is removed, so A \ B = A = {1, 2, 3}, which is NOT the empty set.
e) FALSE. Trap: this is a common misconception. Two nonempty sets can very well be disjoint (share no
elements) without either one being empty — A = {1,2,3} and B = {4,5,6} are a direct counterexample.

Task 13. Sets defined by inequalities

a) False. A contains values like x = 2, which satisfies 1 < 2 < 5 but not 2 ≥ 3, so x = 2 ∈ A but x = 2 ∉ B — this

c) False. B contains values like x = 10, which is not less than 5, so x = 10 ∈ B but x = 10 ∉ A — B is not a

Task 14. Partitions of a set
(source: 1-10logic.docx, original Task 9 — difficulty score 3/8)
Let A = {1, 2, 3, 4, 5, 6}. A partition of A is a collection of nonempty, pairwise disjoint subsets whose union is A.
General Solution: A valid partition needs blocks that are (1) nonempty, (2) pairwise disjoint, and (3) collectively
cover every element of A exactly once. Check each candidate against all three: P={{1,2},{3,4},{5,6}} passes; Q
fails disjointness (3 appears twice); R fails coverage (misses 6). There's no rule tying the number of blocks to |A|.
a) P = { {1,2}, {3,4}, {5,6} } is a partition of A.
b) Every partition of a set must have exactly the same number of blocks as the set has elements.
c) Q = { {1,2,3}, {3,4,5,6} } is a partition of A.
d) R = { {1,2}, {3,4}, {5} } is a partition of A.
e) A set with n ≥ 2 elements always has more than one possible partition.
Explanations:
a) True. The three blocks are nonempty, pairwise disjoint, and their union {1,2,3,4,5,6} equals A — all
partition requirements are satisfied.
b) False. A partition can have any number of blocks, from 1 (the whole set as a single block) up to n (all
singletons) — there's no requirement that the number of blocks equals |A|, as (a) already shows with 3 blocks
for 6 elements.
c) False. The blocks {1,2,3} and {3,4,5,6} both contain the element 3, violating the requirement that blocks be
pairwise disjoint.
d) False. The union of R's blocks is {1,2,3,4,5}, which misses the element 6 — the blocks don't cover all of A.
e) True. For any n ≥ 2, at least two distinct partitions always exist — for example, the single block {A} itself,
and the partition into all singletons — and these are different whenever n ≥ 2.
Task 15. Symmetric difference
(source: 1-10logic.docx, original Task 8 — difficulty score 3/8)
For two sets, define the symmetric difference AΔB = (A \ B) ∪ (B \ A), the elements belonging to exactly one of the
two sets. Let A = {1, 2, 3, 4} and B = {3, 4, 5, 6}.
General Solution: A\B={1,2} and B\A={5,6}, so AΔB = {1,2}∪{5,6} = {1,2,5,6}, with |AΔB|=4. Since A\B and
B\A are always disjoint from each other, their UNION (not intersection) is the correct formula; and since
A∩B={3,4} is exactly what AΔB excludes, the two are always disjoint from one another too.
a) AΔB = {1, 2, 5, 6}.
b) The symmetric difference can also be written as AΔB = (A \ B) ∩ (B \ A).
c) A ∩ B ⊆ AΔB.
d) If A and B are disjoint, then AΔB = A ∪ B.
e) |AΔB| = |A| + |B| − 2|A ∩ B|.
===== PAGE 9 =====
Explanations:
a) True. A \ B = {1,2} and B \ A = {5,6}; their union is {1,2,5,6}.
b) False. A \ B and B \ A are always disjoint from each other (one requires being outside B, the other requires
being inside B), so their intersection is always empty — this can never equal the actual (generally nonempty)
symmetric difference, and the correct connective is ∪, not ∩.
c) False. A ∩ B = {3,4}, which by definition is exactly what symmetric difference excludes (it only keeps
elements in exactly one set) — so A∩B and AΔB are disjoint here, not one contained in the other.
d) True. If A ∩ B = ∅, then A \ B = A and B \ A = B, so AΔB = A ∪ B.
e) True. Here |A|=4, |B|=4, |A∩B|=2, giving 4+4−2(2)=4, matching |{1,2,5,6}|=4 — and this identity holds in
general.
Task 16. Sales rep to client account coverage
(source: 36-45logic.docx, original Task 28 — difficulty score 3/8)
A consulting firm has 5 sales reps and 8 client accounts. A "coverage assignment" is an ordered pair (rep, account)

Task 21. Infinite sets and cardinality
(source: 1-10logic.docx, original Task 10 — difficulty score 6/8)
Let N = {1, 2, 3, ...} be the natural numbers and E = {2, 4, 6, ...} be the even natural numbers.

every even number is hit exactly once), so despite E being a proper subset of N (it excludes all odd numbers), E and
N have the SAME cardinality — the classic infinite-set phenomenon where "proper subset" no longer implies
"fewer elements."
a) E is a proper subset of N.
b) Since E is a proper subset of N, E must have strictly fewer elements than N.
c) The function f(n) = 2n defines a one-to-one correspondence (bijection) between N and the odd natural
numbers.
d) The fact that E ⊊ N yet has the same cardinality as N shows that the finite-set intuition “proper subset ⇒
fewer elements” does not carry over to infinite sets.

a) True. Every even number is a natural number, so E ⊆ N; and 1 ∈ N but 1 ∉ E, so the inclusion is strict
(proper).

despite being a proper subset, E has exactly the same cardinality as N, not fewer elements.
c) False. Trap: f(n) = 2n always produces an EVEN number, so its outputs land in E (the even naturals), never
in the odd naturals — it cannot possibly be a bijection onto the odd numbers, since it never even reaches them.
d) True. This is precisely the classical insight (going back to Cantor and earlier to Galileo) that infinite sets can
be in bijection with a proper subset of themselves, unlike finite sets.
e) False. Trap: this confuses "same cardinality" with "being the same set." E itself is an infinite subset of N with
the same cardinality as N, yet E ≠ N — E excludes every odd number, such as 1. Equal cardinality does not

1. If Petra reviews, then Quinn does not review.
2. Ravi reviews unless Sana reviews.
3. If Quinn does not review, then Theo reviews.
4. At least one of Petra or Sana reviews.
5. If Theo reviews, then Ravi does not review.
6. Sana reviews only if Petra reviews.
General Solution: Assuming Petra does NOT review forces Sana out too (rule 6's contrapositive), which then
breaks rule 4 entirely — so Petra must always review. From there, one unbroken chain (rules 1→3→5→2) forces
every other variable in turn (Quinn out, Theo in, Ravi out, Sana in), leaving no freedom anywhere — a fully unique
solution.
Statements (True / False):
a) Petra must review the paper in every valid assignment.
b) If Quinn reviews, then Petra does not review.
c) It is possible for Ravi to review the paper in some valid assignment.
d) In the (unique) valid assignment, both Theo and Sana review the paper.
e) There are multiple different valid ways to assign reviewers consistent with all six rules.
Answers & Explanations:
a) TRUE. Suppose Petra does not review. Rule 6's contrapositive (¬Petra → ¬Sana) forces Sana out too. But
then rule 4 (Petra or Sana) has both sides false — violated! So Petra not reviewing is impossible; Petra must
always review.
b) TRUE. This is the contrapositive of rule 1 (Petra → ¬Quinn becomes Quinn → ¬Petra) — a structural
guarantee, always true.
c) FALSE. Trap: tracing the forced chain from Petra = in: rule 1 forces Quinn out, rule 3 then forces Theo in,
rule 5 then forces Ravi out. Since Petra is always in (part a), this chain always fires, so Ravi is always forced
out — never able to review.
d) TRUE. Continuing the chain from part (c): Theo is forced in, and rule 2's contrapositive (¬Ravi → Sana)
forces Sana in once Ravi is forced out. Both Theo and Sana are in in the one valid assignment.

e) FALSE. Trap: as shown above, once Petra = in is forced, every other variable (Quinn, Theo, Ravi, Sana) is
forced in a single unbroken chain — leaving no freedom anywhere. The assignment is completely unique, not
one of several options.

Task 87. Seven Finalists and the Tournament Roster
(new — rule-based deduction puzzle, SUPER DUPER HARD)
Seven finalists — Uma, Victor, Wendy, Xavier, Yara, Zane, and Bianca — are deciding whether to compete in a
tournament. Their participation follows these rules:
1. Uma competes if and only if Victor competes.
2. If Victor competes, then Wendy competes.
3. Exactly one of Wendy or Xavier competes (never both, never neither).
4. If Xavier competes, then Yara does not compete.
5. At least one of Yara or Zane competes.
6. Zane competes only if Bianca does not compete.
7. If Bianca competes, then Uma competes.
8. At least four of the seven finalists compete.
General Solution: Testing Victor=out leads to two sub-branches (split on rule 3), and BOTH fail the "≥4 compete"
threshold — so Victor (and hence Uma, by rule 1) must always compete, which then forces Wendy in and Xavier
out (rule 3). From there, Yara/Zane/Bianca retain genuine freedom (subject to rules 5 and 6), giving multiple valid
rosters overall, though never one with Xavier in, and never one hitting exactly six competitors (since that would
require Zane and Bianca both in, violating rule 6).
Statements (True / False):
a) Victor must compete in every valid roster.
b) It is possible for Xavier to compete in some valid roster.
c) If Bianca competes, then Zane does not compete.
d) There is exactly one valid way to build the roster, consistent with all eight rules.
e) It is possible for exactly six of the seven finalists to compete.
Answers & Explanations:
a) TRUE. Suppose Victor does not compete (so Uma doesn't either, by rule 1). Rule 7's contrapositive forces
Bianca out too. Now split on rule 3: if Wendy competes and Xavier doesn't, the maximum possible headcount
— even with both Yara and Zane in — is only 3 (Wendy, Yara, Zane), short of the required 4. If Xavier
competes and Wendy doesn't, rule 4 forces Yara out, and rule 5 then forces Zane in, giving only 2 competitors
(Xavier, Zane) — even further short. Both branches violate rule 8, so Victor not competing is entirely
impossible; Victor must always compete.
b) FALSE. Trap: since Victor always competes (part a), rule 2 forces Wendy in every time, and rule 3 (exactly
one of Wendy/Xavier) then forces Xavier out every time — Xavier can never compete.
c) TRUE. This is the contrapositive of rule 6 (Zane → ¬Bianca becomes Bianca → ¬Zane) — a structural
guarantee, always true regardless of the specific roster.
d) FALSE. Trap: with Uma, Victor, Wendy always in and Xavier always out, rules 5 and 6 still leave real
freedom among Yara, Zane, and Bianca — e.g., (Yara in, Zane out, Bianca out), (Yara in, Zane out, Bianca in),
(Yara out, Zane in, Bianca out), and (Yara in, Zane in, Bianca out) are all separately valid. Several distinct
rosters satisfy every rule, so the solution is not unique.

e) FALSE. Trap: exactly six competing would require every finalist except Xavier to be in — meaning Yara,
Zane, AND Bianca would all have to compete together. But rule 6 forbids Zane and Bianca competing
simultaneously (Zane → ¬Bianca), so that combination is never valid — exactly six can never be achieved.
