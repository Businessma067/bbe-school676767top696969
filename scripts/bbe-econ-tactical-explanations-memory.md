# BBE economics tactical explanations memory

Use this whenever you write or rewrite `tactical_explanations` for economics Full Course / Custom Mock Builder banks (chapters 2–6).

Goal: same living teacher feel as math tactical explanations (`scripts/bbe-tactical-explanations-memory.md`), adapted to conceptual and ratio work.

## Shape

Practice UI already prints `**A.** → True/False` above each letter. The stored explanation is the **body only**.

```text
Even a steady salary remains finite. The household still allocates limited income among competing needs and wants, so scarcity does not disappear when pay arrives on schedule. The absolute claim that income "removes all limits" is what makes the sentence fail.

The statement is false.
```

For ratio / accounting letters, show the arithmetic in order:

```text
Current assets are 184 and current liabilities are 100.

Current ratio = 184 / 100 = 1.84

That sits above the claim's threshold, so the direction matches.

The statement is true.
```

## Required

- Calm tutor English. Short and medium sentences.
- Every calculation step when figures exist (identity → substitute → result → compare).
- Plain closing: `The statement is true.` / `The statement is false.`
- Expand thin ideas: say *why*, not only the one-line verdict.

## Forbidden

- `TRUE —` / `FALSE —` leads
- Em dashes (`—`) and dash piles
- Stamped method openers ("Read the quantifier…", "Map the scenario…", "This statement draws on…")
- "A student who overlooked…", "Mark the statement true", "It is important to note", "In conclusion"
- Fake enthusiasm or tip-sticker spam (`**Watch.**`, `**Trap:**`)
